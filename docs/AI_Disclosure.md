# AI Disclosure
Some code, data, and documentation in this project was created or refined with the assistance of LLMs.
AI was used as a development aid, primarily to speed up tasks such as analyzing decompiled game code to identify hooks and understand function implementations, assisting with mod and client-side code, and keeping documentation accurate and up to date.

The overall concept, architecture, and majority of the code are my own work, written by hand.
AI-generated contributions were reviewed, adapted where necessary, and tested in-game before being included.
